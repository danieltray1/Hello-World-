# Daniel Tray - Python Programming Projects

## Project Title
**Python Homework 1 and Homework 2**

## Description
This repository contains two Python homework assignments that I completed while learning programming fundamentals. These projects demonstrate my ability to work with variables, user input, calculations, conditional statements, and decision-making logic.

### Homework 1
Homework 1 includes four programming exercises:
1. Calculating the total cost of a purchase, including sales tax.
2. Calculating employee wages and overtime pay.
3. Converting numerical grades into letter grades.
4. Determining employee bonus eligibility based on hours worked and performance.

### Homework 2
Homework 2 includes two programming scenarios:
1. **Gym Membership Discount Calculator:** Calculates membership fees for Basic, Premium, and Elite members, including age-based discounts.
2. **Seasonal Product Stock Alert:** Uses randomly generated inventory levels and seasonal conditions to determine whether products need to be restocked.
